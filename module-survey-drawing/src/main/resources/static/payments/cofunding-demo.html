응답은 접수증 — 좌표(fundingId)와 접수 사실(status)뿐. deadline 은 에코라 없고, inviteUrl 은 확정의 산물이라 폴링이 준다.

02

폴링

GET /api/v1/co-fundings/{fundingId}

1초 간격. sharedAmount 0 → 확정값, inviteUrl null → 지급 — 그 줄이 approve CAS 의 순간이다.
